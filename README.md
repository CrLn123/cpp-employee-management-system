# C++ 职工管理系统

这是在学习 C++ 面向对象编程时完成的课程练习项目。

项目的整体框架参考了黑马程序员的 C++ 课程，具体功能由我跟随课程学习并独立编码、调试完成。它是我目前完成的第一个相对完整的 C++ 小项目。项目本身不复杂，但在实现过程中，我第一次把类、继承、多态、动态内存和文件读写放到同一个程序中使用，也遇到并解决了一些只看课程时没有意识到的问题。

## 实现的功能

- 添加职工
- 显示职工信息
- 删除职工
- 修改职工信息
- 按编号或姓名查找职工
- 按职工编号排序
- 清空职工数据
- 将数据保存到本地文件，并在程序启动时重新读取

## 项目结构

- `Worker.h`：职工抽象基类
- `Employee.h/.cpp`：普通员工类
- `Manager.h/.cpp`：经理类
- `Boss.h/.cpp`：老板类
- `workManager.h/.cpp`：负责职工数据和各项功能的管理类
- `职工管理系统.cpp`：程序入口和菜单交互
- `职工名单.txt`：保存职工数据

## 用到的知识

- 类与对象
- 继承和多态
- 纯虚函数与抽象类
- 虚析构函数
- 指针和动态内存管理
- 文件输入与输出
- 简单的查找和排序
- 多文件项目组织

## 运行方式

本项目使用 Visual Studio 开发。

1. 下载或克隆仓库；
2. 使用 Visual Studio 打开 `职工管理系统2.sln`；
3. 编译并运行项目；
4. 根据控制台菜单输入对应编号。

```bash
git clone https://github.com/CrLn123/cpp-employee-management-system.git
```

## 目前的不足

这个项目主要用于练习 C++ 基础，仍有很多可以改进的地方：

- 使用了原始指针和动态数组，内存管理比较繁琐；
- 输入校验不够完善，输入错误类型的数据时可能导致程序异常；
- 排序和查找采用了较基础的实现，数据量较大时效率不高；
- 代码依赖 Windows 控制台命令，可移植性不足；
- 没有自动化测试；
- 文件格式比较简单，缺少异常数据处理。
