# C++ 职工管理系统

这是我跟着黑马程序员 C++ 课程完成的练习项目。课程提供了整体框架，具体功能由我在学习过程中自己编码和调试。

这是我完成的第一个较为完整的 C++ 小项目。写完之后，我对类、继承、多态、动态内存和文件读写有了更具体的认识，也发现能听懂课程和自己把程序调通是两回事。

## 主要功能

- 添加职工
- 显示职工信息
- 删除职工
- 修改职工信息
- 按编号或姓名查找职工
- 按职工编号排序
- 清空职工数据
- 将数据保存到本地文件，并在程序启动时重新读取

## 文件结构

- `Worker.h`：职工抽象基类
- `Employee.h/.cpp`：普通员工类
- `Manager.h/.cpp`：经理类
- `Boss.h/.cpp`：老板类
- `workManager.h/.cpp`：负责职工数据和各项功能的管理类
- `职工管理系统.cpp`：程序入口和菜单交互
- `职工名单.txt`：保存职工数据

## 如何运行

本项目使用 Visual Studio 开发。

1. 下载或克隆这个仓库；
2. 用 Visual Studio 打开 `职工管理系统2.sln`；
3. 编译并运行；
4. 按照控制台菜单输入功能编号。

```bash
git clone https://github.com/CrLn123/cpp-employee-management-system.git
```

## 已知问题

项目目前还有这些不足：

- 使用了原始指针和动态数组，内存管理比较繁琐；
- 输入校验不够完善，输入错误类型的数据时可能导致程序异常；
- 排序和查找的实现比较基础，数据量较大时效率不高；
- 代码依赖 Windows 控制台命令，可移植性不足；
- 没有自动化测试；
- 文件格式比较简单，缺少异常数据处理。
